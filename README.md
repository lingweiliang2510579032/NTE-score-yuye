# yuye 评分包

基于异环工坊开放接口的角色词条权重，实现 350 满分制装备评分，
与异环工坊小程序「评分总览」同口径。包名 `yuye`，作者雨夜。

## 使用

1. 把本目录（`yuye/`）放到 `NTEUID/scoring/scorers/` 下
2. 机器人里执行 `scorer设置 yuye` 切换评分算法
3. 重启或重新激活后生效

## 数据来源

`data/weights.json` 来自异环工坊开放接口（角色词条权重），
已获得授权使用，请勿公开传播或用于其它项目。
